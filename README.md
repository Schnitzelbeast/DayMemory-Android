# DayMemory Android

Installierbare Debug-APK von DayMemory. Dieses Repository enthält bewusst keinen Quellcode.

## Installation

1. APK auf ein Android-Gerät laden.
2. Installation aus dieser Quelle erlauben.
3. `DayMemory-4.11-debug.apk` öffnen und installieren.

Die App ist derzeit eine Debug-Version und nicht für Google Play bestimmt.
